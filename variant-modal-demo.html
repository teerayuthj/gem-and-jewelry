วิธีการใช้งาน

ขั้นตอนการนำไปใช้:

  1. เพิ่ม CSS file ลงใน HTML: <link rel="stylesheet" href="assets/css/variant-modal-enhanced.css">
  2. เพิ่ม class variant-modal enhanced-style หรือ luxury-style ใน variant-modal container
  3. เพิ่ม HTML elements สำหรับ effects (ดูตัวอย่างในไฟล์นี้):
  • glow-ring - สำหรับ Enhanced Style
  • gold-border + sparkle-container - สำหรับ Luxury Style
  • shine-effect - สำหรับทั้งสองแบบ

สำหรับ JavaScript สำหรับ mouse tracking และ selection, ดูได้ที่ด้านล่างของไฟล์นี้
